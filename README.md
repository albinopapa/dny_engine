dny_engine plans to be a 2.5D game engine for making metroidvania genre of games. The 2.5D is defined in this context as having a 2D action plane in a 3D environment.
Enemies and the player as well as all interactable objects are locked into the same Z depth.
The engine will use a custom 3D software renderer designed to be compile time configurable.
All entities will be textured quads while the terrain will be a mesh.
